## Project Exam Brief

### Description

Holidaze, a new accommodation booking site, has asked you to develop a modern front end for its application. While feature requirements are provided, design and UX are up to you.

**Build using the official API documentation.**

**Customer-facing:** users can browse venues and make bookings.<br/>
**Admin-facing:** venue managers can register venues and manage bookings.

### Steps to follow

- Create a GitHub repository and deploy your code.
- Create a Kanban plan in Trello or GitHub Projects (include a Roadmap View if using GitHub).
- Create a Figma Style Guide (logo, fonts, colour palette, common components).
- Create desktop and mobile prototypes in Figma.
- Use your plan and design documents to complete user stories; commit frequently to main/master.
- Write a detailed README.md (setup and run instructions).
- Manually test each user story.
- Validate with online tools: HTML Validator, Lighthouse, WAVE.
- Deploy with GitHub Pages, Netlify, or Vercel.
- Submit required links.

### User Stories

**Visitor:** A user who has not registered or logged in.<br/>
**Customer:** A registered user logged in as a customer.<br/>
**Venue Manager:** A registered user logged in as a Venue Manager.

#### All Users

- View a list of Venues.
- Search for a specific Venue.
- View a Venue page by ID.
- Register as a Customer or Venue Manager (stud.noroff.no email).
- View a calendar with available and booked dates.

#### Venue Managers

- Log in and log out.
- Create, edit, and delete a Venue.
- View upcoming bookings for the Venues they manage.
- Update avatar/profile picture.

#### Customers

- Log in and log out.
- Create a booking.
- View upcoming bookings.
- Update avatar/profile picture.
