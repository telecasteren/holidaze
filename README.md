## Installation

Clone the repository

```bash
git clone https://github.com/telecasternilsen/holidaze.git
```

Navigate to the project directory

```bash
cd holidaze
```

Install dependencies and run the app

```bash
pnpm install
pnpm dev
```

Build this app for production

```bash
pnpm build
```
